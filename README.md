# EJP Hand Poser

Finger posing for Blender 4.2 and later: pose library, shape sliders, drag to pose, wrap around a prop,
Pose Doctor. Built for Auto-Rig Pro; other rigs are found from the mesh weights, or set up once by hand.

## Download

[Latest release](https://github.com/energyjp/hand-poser/releases/latest): `ejp_hand_poser_lite_1.0.0.zip`.
Free, every tool, 8 poses (Flat, Relaxed, Fist, Peace, Finger Gun, Point, Thumbs Up, Pinch).

## Install

Blender: Edit > Preferences > Get Extensions > the arrow at the top right > Install from Disk, pick the zip.
The panel is in the 3D Viewport sidebar (N), Hand tab. The controls are in `CONTROLS.txt` inside the zip.
